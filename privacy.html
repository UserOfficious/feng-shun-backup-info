Feng Shun Local Backup

Privacy information

Updated October 18, 2026. This page describes the private local backup tool operated by its account owner.

Google Drive access

The tool requests the drive.file permission. It creates a private backup folder, uploads encrypted archives, and reads their metadata and encrypted contents to verify successful storage. It does not need access to unrelated Drive files.

Data processing and storage

The tool reads website data from the owner's Cloudflare database, validates it locally, encrypts the archive, and uploads it to the owner's Google Drive. Temporary unencrypted working files are removed after each run. Backup credentials are stored locally using Windows CurrentUser DPAPI, outside the source repository. No backup data or credentials are sent to this documentation website.

Sharing and retention

The tool creates owner-only Drive files and does not add other recipients. Existing backup copies are retained until the owner removes them. Google and Cloudflare process data through their services under their own applicable terms and privacy policies.

Owner controls

The owner can disable the Windows scheduled task, revoke this app's Google authorization from Google Account permissions, and delete backup copies in Drive. Revoking access stops future uploads; it does not delete existing copies.

This documentation website

This static site has no sign-in form, analytics script, advertising, or backup upload endpoint. Its hosting provider may process ordinary website requests under its own privacy policy. Questions can be directed to the owner through the repository hosting this page.
